# محاكاة السجل المدني المحلية

المحاكاة مفعلة محليًا في هذا المشروع. افتح `/integrations/civil-registry-demo` بحساب أدمن أو موظف نشط. توجد وصلة في صفحة إدارة التكامل وصفحة طلبات التحقق الإلكتروني.

## التجربة

| الرقم | الاسم | النتيجة |
|---|---|---|
| 99000000001 | مواطن تجريبي أول | تطابق تجريبي |
| 99000000001 | أي اسم مختلف | اختلاف البيانات |
| 99000000009 | أي اسم | سجل غير موجود |
| 99000000002 | مواطن تجريبي ثان | خدمة غير متاحة |

لا تحتاج تسجيل هذه الأسماء كحسابات أو تقديم طلب. البيانات الوهمية موجودة في `config/civil_registry_demo.php`، وليست في جداول المواطنين. لا تدخل بيانات حقيقية. الطلبات محمية بالمصادقة والدور وCSRF، مع حد 30 محاولة في الدقيقة وعدم تخزين الصفحة مؤقتًا.

## التفعيل

```dotenv
APP_ENV=local
CIVIL_REGISTRY_DEMO=true
```

بعد تغيير الإعدادات: `php artisan config:clear`. القيمة الافتراضية في `.env.example` معطلة. أي بيئة غير `local` ترفض العرض والتنفيذ حتى لو كان العلم مفعلاً.

## الحدود

هذه شاشة محاكاة مستقلة ضمن قسم التكامل، وليست استعلامًا رسميًا ولا اعتمادًا لهوية الحساب أو أهلية الخدمة. لا تُعدل سجلات المستخدمين أو الطلبات أو الوثائق أو محاولات التكامل، ولا تنفذ اتصال شبكة أو تخزن أسماء المدخلات أو أرقامها في سجل مخصص. Laravel قد يحتفظ بإدخال نموذج غير صالح مؤقتًا داخل جلسة صاحبه لعرض أخطاء التحقق.

`LocalCivilRegistryProvider` يطبق العقد الحالي، لكن دالة `verify` الرسمية تعيد دائمًا `unknown` و`bound=false`؛ فقط `simulate` تعيد النتيجة التجريبية للواجهة. المزود مسجل بوصف تجريبي و`approved=false`. لا تختَر المحاكاة كمتطلب إلزامي لخدمة حقيقية؛ ستظل غير متحقق منها. لا تستبدل المحول الرسمي بهذا المحول عند توفير API الحقيقي.
