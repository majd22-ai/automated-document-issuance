# الفحص التقني للصورة الشخصية

## التنفيذ

لم يكن هناك محرك OpenCV مرتبط بالخطوة الرابعة في النسخة المفحوصة. أضيف scripts/photo_quality.py وخدمة App\Services\PhotoQuality إلى المسارات القائمة دون جداول إضافية.

- يفحص Laravel الملف أولًا، ثم يشغّل Python محليًا بوسائط منفصلة دون تركيب أمر shell. لا يُرسَل الملف إلى خدمة خارجية.
- تُقاس الضبابية بتباين Laplacian على منطقة الوجه بعد توحيد مقاسها. تستخدم واجهة [OpenCV Laplacian](https://docs.opencv.org/4.11.0/d4/d86/group__imgproc__filter.html).
- يتم اكتشاف الوجه الأمامي باستخدام Haar cascade المرفق بحزمة OpenCV. صفر وجوه أو أكثر من وجه يؤدي للرفض برسالة عربية.
- تُفحص إضاءة الوجه بمتوسط السطوع ونسب البكسلات المظلمة/المشبعة والفروق بين نصفي الوجه أفقيًا ورأسيًا.
- تُفحص عينات من الحدود العليا والجانبية للخلفية باستخدام HSV، مع استبعاد مناطق الوجه، ونسبة البياض وتفاوت السطوع. هذه عينات تقريبية وليست تجزئة دقيقة لكامل الخلفية.
- القيم الافتراضية قابلة للضبط في config/photo_quality.php. لم تُعايَر على مجموعة صور مواطنين، ولا توجد نسبة دقة مقاسة. يجب معايرتها ببيانات مأذون باستخدامها ومراجعة أثرها على درجات البشرة والإضاءة والملابس المختلفة.
- القبول التقني ليس قبول الموظف النهائي. لا يثبت حداثة الصورة أو هوية صاحبها أو أنها لم تُلتقط من شاشة أو ورقة، ولا يكشف جميع الفلاتر أو التعديلات، ولا يتحقق من الرأس الكامل أو اتجاه الوجه بدقة.
- لا تُحفظ صور وجه مقتطعة أو بصمات/قوالب حيوية، ولا تُسجل الصور أو المسارات أو مخرجات Python الخام. تبقى الصورة المقبولة في التخزين الخاص القائم وبحالة pending للمراجعة.

## نقاط الربط

الفحص قبل حفظ الصورة في IdentityCardForms، وعند استبدال مرفق من نوع photo لخدمة identity-first-issue في ManageAttachments، وقبل الإرسال النهائي لمنع تجاوز الفحص بصورة قديمة أو مرفق بديل. الرفض لا يتلف الصورة السابقة ولا يسمح بالانتقال للمرحلة التالية. الفشل أو المهلة أو استجابة غير سليمة تُظهر عدم توفر الفحص، ولا تتحول إلى قبول صامت.

## إعداد Windows / PowerShell

### تحقق الإعداد المحلي — 2026-11-07

كشف الاختبار عبر HTTP أن مفسر Microsoft Store لا يجد `cv2` عند تشغيله من خادم الويب، رغم نجاح استيراد المكتبة من الطرفية. لذلك جُهزت بيئة مشروع معزولة `.venv-photo` باستخدام `scripts/requirements-photo.txt`، وضبط `PHOTO_QUALITY_PYTHON` في `.env` المحلي إلى `C:/Users/w3h333/e-issuance/.venv-photo/Scripts/python.exe`، ثم مسح كاش إعدادات Laravel. مجلد البيئة مستبعد من Git. نجاح الطرفية وحده غير كافٍ للتحقق من هذا الإعداد؛ يلزم اختباره من خادم HTTP أيضًا.

نجح استدعاء سكريبت الفحص من Laravel فعليًا على صورة الاختبار المحلية: خرج العملية 0، ووجه واحد، والنتيجة التقنية `accepted: true`. لا تمثل هذه النتيجة اعتماد هوية أو موافقة رسمية. لم تتغير عتبات الفحص أو شروط قبول الصور.

البيئة الحالية تحتوي Python 3.11 وOpenCV 4.12.0 وNumPy 2.2.6 بالفعل. ضُبط PHOTO_QUALITY_PYTHON في .env المحلي لمسار المفسر المثبت، دون تثبيت حزم جديدة أو تغيير النظام. في جهاز آخر، يمكن تجهيز بيئة منفصلة من مجلد المشروع:

```powershell
py -3.11 -m venv .venv-photo
.\.venv-photo\Scripts\python.exe -m pip install -r scripts/requirements-photo.txt
```

في .env عيّن المسار المطلق للمفسر (بدّل المسار إذا اختلف مكان المشروع):

```dotenv
PHOTO_QUALITY_PYTHON="C:/Users/w3h333/e-issuance/.venv-photo/Scripts/python.exe"
```

ثم:

```powershell
php artisan config:clear
.\.venv-photo\Scripts\python.exe -c "import cv2; print(cv2.__version__)"
.\.venv-photo\Scripts\python.exe -m unittest discover -s tests/python -v
php vendor/phpunit/phpunit/phpunit --filter="PhotoQualityTest|IdentityCardWizardTest|CitizenAttachmentsTest|IdentityFingerprintWorkflowTest" --do-not-cache-result
```

أعد تشغيل خادم PHP طويل العمر إن كان يحتفظ بإعدادات سابقة. لا تعطّل الفحص عند تعطل المحرك؛ هيئ المفسر والحزم أولًا.

## نتائج التحقق وحدوده

منع العزل تشغيل اختصار Python في البداية؛ نجح تشغيل المفسر المثبت خارج العزل. نجحت اختبارات Python الثمانية، وتتضمن الفحوص العددية بصور اصطناعية، وكاشفًا حقيقيًا على صورة فارغة وصورة Grace Hopper العامة المرفقة بـMatplotlib، ثم صورتين متجاورتين منها. Matplotlib اختياري للاختبار فقط ولا يلزم للمحرك. نجح اختبار حي من Laravel إلى المحرك يرفض صورة فارغة بسبب عدم وجود وجه. اختبارات سير العمل الأخرى تحاكي استجابة العملية لعزل الربط والرسائل والحماية، ولا تقيس دقة الكاشف على صور المواطنين. لم يُجر اختبار بصري من متصفح الجوال أو معايرة لمجموعة صور حقيقية متنوعة.

لتشغيل اختبار Laravel الحي اختياريًا:

```powershell
$env:PHOTO_QUALITY_LIVE_TEST = '1'
php vendor/phpunit/phpunit/phpunit --filter=test_live_engine_rejects_a_generated_blank_image --do-not-cache-result
Remove-Item Env:PHOTO_QUALITY_LIVE_TEST
```
