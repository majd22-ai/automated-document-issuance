# إدارة المستخدمين والمصادقة

نتائج التحقق الفعلية: نجح 27 اختبارًا و184 تحققًا على SQLite، ونجح العدد نفسه على MySQL المحلي بعد إعادة تشغيل الخادم المتوقف. نجحت اختبارات الواجهة الخمسة، وتجميع Blade وفحص Pint للملفات المعنية وتوليد المعاينة الثابتة. تم التحقق من استجابات HTTP باختبارات Laravel؛ لم يجر فحص بصري في متصفح. لم تُحذف بيانات سابقة ولم تُضف مكتبات جديدة.

تم الحفاظ على نظام جلسات Laravel والواجهات الحالية دون إضافة مكتبات. الإصدار المفحوص: Laravel 12.65.0 وPHP 8.2.12.

## قاعدة البيانات

الاتصال المحلي في `.env` يستخدم `mysql` وقاعدة `e_issuance`. خادم XAMPP المتاح هو MariaDB 10.4.32 المتوافق مع MySQL. تم الاحتفاظ بملف SQLite السابق؛ كان عدد المستخدمين فيه صفرًا عند الفحص. قاعدة `e_issuance_auth_testing` منفصلة للاختبارات.

الترحيل `2026_10_21_000001_complete_user_authentication_fields` يضيف فقط الحقول الناقصة: `username` و`role` و`phone` و`is_active`. لم يتغير ترحيل إنشاء المستخدمين الأصلي، ويظل البريد فريدًا. دالة `down` تحتفظ بهذه الحقول عمدًا حتى لا تحذف بيانات حسابات أو حقولًا سابقة للترحيل.

## السلوك

- التسجيل ينشئ مواطنًا نشطًا فقط. الرقم الوطني محفوظ في `username` وفق النظام السابق. الهاتف اختياري.
- الدخول بالبريد أو اسم المستخدم/الرقم الوطني، مع تجزئة Laravel لكلمات المرور وتجديد الجلسة. الخروج يبطل الجلسة ويجدد CSRF.
- الحساب المعطل لا يستطيع الدخول، وتُنهى جلسته إذا عُطّل بعد الدخول.
- `/profile` يعرض حساب المستخدم الحالي فقط؛ `PATCH /profile` يقبل الاسم والبريد والهاتف فقط. تغيير البريد يلغي تاريخ التحقق السابق؛ التحقق بالبريد غير مفعل في المشروع الحالي.
- مجموعات `/citizen` و`/employee` و`/admin` محمية بالمصادقة والدور. إدارة الأدوار وحالة الحساب متاحة للمدير في `/admin/users` فقط؛ لا يستطيع المدير تعطيل نفسه أو إزالة دوره بنفسه.
- تسجيل الدخول محدود بست محاولات في الدقيقة والتسجيل بعشر محاولات، مع حماية CSRF القائمة.
- لم يتم تنفيذ تقديم طلبات الوثائق أو إعادة تعيين كلمة المرور؛ صفحة استعادة كلمة المرور التجريبية القائمة بقيت كما هي.

## تهيئة أول مدير

لا يوجد حساب مدير أو كلمة مرور افتراضية. سجّل الحساب المقصود أولًا، ثم ينفذ مسؤول الخادم الموثوق `php artisan tinker` ويستبدل البريد التالي بالبريد الفعلي:

```php
$user = App\Models\User::where('email', 'admin@example.test')->firstOrFail();
$user->forceFill(['role' => 'admin'])->save();
```

هذه صلاحية محلية لمسؤول الخادم وليست خيارًا في التسجيل أو الملف الشخصي. بعدها تتم إدارة بقية الأدوار من واجهة المدير.

## التشغيل والاختبارات

مع تشغيل MySQL في XAMPP:

```powershell
php artisan config:clear
php artisan migrate
php artisan serve --host=127.0.0.1 --port=8000
```

اختبارات SQLite المعزولة:

```powershell
php vendor/bin/phpunit --do-not-cache-result
```

اختبارات MySQL في جلسة PowerShell منفصلة:

```powershell
$env:DB_CONNECTION='mysql'
$env:DB_HOST='127.0.0.1'
$env:DB_PORT='3306'
$env:DB_DATABASE='e_issuance_auth_testing'
$env:DB_USERNAME='root'
$env:DB_PASSWORD=''
php vendor/bin/phpunit --do-not-cache-result
```

استخدم بيانات اتصال بيئتك عند اختلافها. الاختبارات ترفض قاعدة غير ذاكرية لا ينتهي اسمها بـ `_testing`، وتطبق الترحيلات المعلقة ثم تتراجع عن بيانات معاملاتها فقط. لا تستخدم إعادة إنشاء قاعدة البيانات. اختبار الترحيل القديم يستخدم اتصال SQLite مستقلًا في الذاكرة.

الملفات الجديدة: متحكمات `AuthController` و`ProfileController` و`AdminUserController`، وسيطا `EnsureAccountIsActive` و`EnsureUserHasRole`، ترحيل استكمال المستخدمين، صفحة `profile/edit`، اختبارات `UserAuthenticationTest` و`UserSchemaMigrationTest`، وأداة `scripts/inspect-auth-schema.php` التي تعرض البنية والعدد دون بيانات المستخدمين.

الملفات المعدلة: `app/Models/User.php` و`bootstrap/app.php` و`routes/web.php` وواجهتا `auth/login` و`auth/register` و`admin/users/index` و`components/public-header` و`scripts/build-demo-shell.php`، وإعداد الاتصال المحلي في `.env`. معاينة `public/demo/index.html` تعاد توليدها من المكونات المشتركة.
