# تحديث الفوتر

التصميم RTL بثلاث مجموعات: عن المنصة، السياسات والإرشادات، والمساعدة والدعم. تظهر في ثلاثة أعمدة من 768 بكسل فأكثر، وفي عمود واحد على الجوال، بقوائم مطوية تفتح عند الضغط على العنوان باستخدام JavaScript؛ تفتح مجموعة واحدة في كل مرة ويمكن إغلاقها بزر Escape. عند تعطيل JavaScript تبقى الروابط ظاهرة. الألوان داكنة مع فواصل وأيقونات ذهبية وتركيز ظاهر للوحة المفاتيح، وحقوق نشر بسنة ديناميكية وعبارة «مشروع تخرج أكاديمي — نسخة تجريبية».

الروابط التسعة لا تكرر روابط الهيدر المذكورة في الطلب. صفحات التعريف والأهداف ومعالجة الطلب تشترك في صفحة واحدة بأقسام مخصصة. السياسات ودليل الاستخدام لها صفحات عامة مستقلة بقالب موحد. أعيد استخدام قسم FAQ بالرئيسية ونموذج التواصل لصفحة الإبلاغ التقني، مع بقاء التنبيه بأن النموذج تجريبي ولا يرسل بلاغًا فعليًا.

## الملفات

- `resources/views/components/public-footer.blade.php`: المجموعات والروابط وحقوق النشر.
- `public/css/portal-theme.css`: التنسيق المتجاوب وتنسيق صفحات المعلومات.
- `config/platform_pages.php`: محتوى التعريف والخصوصية والشروط وحماية البيانات ودليل الاستخدام.
- `resources/views/public/platform-info.blade.php`: قالب صفحات المعلومات.
- `routes/web.php`: مسارا صفحات المنصة والإبلاغ التقني.
- `resources/views/public/contact.blade.php`: عنوان ووصف نموذج المشكلة التقنية.
- `resources/views/public/home.blade.php`: تصحيح إرشاد FAQ الذي كان يحيل إلى رابط فوتر أزيل، وتوضيح اختلاف تخزين طلبات الحساب عن تجربة الواجهات المحلية.
- `public/js/footer-mobile.js`: فتح وإغلاق مجموعات الفوتر على الجوال فقط، مع بقاء الأعمدة والروابط ظاهرة على الكمبيوتر.
- `tests/Feature/PublicFooterTest.php`: التحقق من روابط الفوتر وأهداف الأقسام والصفحات وحقوق النشر.

لم يعدل الهيدر أو نظام الصلاحيات أو قاعدة البيانات.

## التحقق الفعلي

نجح اختبارا Laravel بـ64 تأكيدًا: جميع الروابط التسعة ترجع HTTP 200، وجميع أهداف الأقسام موجودة، والصفحات عامة، والصفحة غير المعروفة ترجع 404، والمجموعات ثلاث، ولا توجد روابط وهمية أو تكرارات لعناوين الهيدر المطلوبة. نجحت فحوص PHP وPint للملفات الجديدة وتجميع Blade و`git diff --check` دون أخطاء (مع تنبيهات نهايات الأسطر المعتادة).

```powershell
php vendor/phpunit/phpunit/phpunit --filter=PublicFooterTest --do-not-cache-result
php artisan view:cache
php artisan view:clear
```

راجعت قواعد CSS للمقاسين، لكن لم تتوفر جلسة متصفح قابلة للتحكم للمراجعة المرئية الفعلية على جوال ولابتوب. `ego-browser` غير مثبت، وأداة المتصفح أعادت قائمة متصفحات فارغة. لم أدّع نجاح اختبار مرئي أو التقاط لقطات شاشة.
