# مركز أنظمة المحاكاة

المدخل الموحد للمدير هو `/admin/simulations`، من رابط «مركز أنظمة المحاكاة» في القائمة الجانبية.

يجمع السجل المدني التجريبي، أنظمة التسجيل والتفعيل المدنية، شبكة البريد، محاكاة البصمة والمراجعة الإدارية، وتجربة التحقق المحلية من السجل المدني. تبقى صفحة التكامل الإلكتروني لمراقبة مزودي التحقق والمحاولات والأخطاء، وبها رابط للمركز.

تظهر حالة كل نظام حسب إعداداته الحالية ووجود الجداول المطلوبة. لا يظهر رابط فتح النظام المعطل أو الذي لم تكتمل جداول تهيئته. الحالة لا تعني وجود بيانات تجريبية أو نجاح تكامل رسمي. لا يقوم المركز بتشغيل migrations أو seeders أو تفعيل أي إعداد.

الصلاحيات والمسارات القديمة محفوظة. نافذة السجل المدني داخل مراجعة الطلب محفوظة للموظفين المخولين. روابط البصمة الخاصة بالموظفين في قائمتهم محفوظة؛ روابط المدير التجريبية مجمعة في المركز. ميزة البريد لا تزال للمرحلة الأولى فقط، دون فواتير أو تحصيل.

الملفات الجديدة: `SimulationCenterController.php`، واجهة `admin/simulations.blade.php`، اختبارات `SimulationCenterTest.php` وهذا المستند. الملفات المعدلة: `routes/web.php`، القائمة `operations-sidebar.blade.php` وصفحة `admin/integrations.blade.php`.

الاختبارات تُشغّل على SQLite بالذاكرة فقط. لم تُعدّل قاعدة المشروع أو إعدادات البيئة.
