# تحسين صفحات الإدارة والموظف والإشعارات

## نطاق التعديل

- تحسين قوالب `resources/views/admin/` و`resources/views/employee/` وصفحات العمليات والتحقق وعرض الوثائق المشتركة: ترتيب المحتوى، النماذج والجداول والفلاتر والإجراءات وحالات الفراغ.
- مساحة تنقل أسفل الهيدر في `layouts/public.blade.php` و`components/operations-sidebar.blade.php`، مع إظهار الروابط حسب الصلاحيات الحالية.
- تنسيق RTL متجاوب محصور في مساحة العمل: `public/css/operations-workspace.css`.
- تحسين الوصول للجداول والنماذج وحالة إرسالها: `public/js/operations-workspace.js`.
- لم تُعدّل ملفات `public-header.blade.php` أو `account-navigation.blade.php` أو `portal-theme.css` في هذا المتطلب.

## الإشعارات

- `OperationalNotifications` و`OperationalNotificationObserver` يربطان العمليات المحفوظة بصندوق الإشعارات الحالي؛ تسجيل المراقب في `AppServiceProvider` وتمرير المنفذ في `LockedRequest`.
- الإدارة ← الموظف المستهدف: تغييرات الحساب والصلاحيات وطلب استعادة كلمة المرور الناجح، مع إبقاء إشعار منح التفعيل الموجود دون تكرار.
- المواطن ← الموظف المختص: إجراءات المراجعة والمرفقات والمواعيد والفحص والدفع والتحقق والوثائق، مع إعادة استخدام إشعارات الحالات الموجودة.
- الموظف المسند إليه الطلب ← المواطن: تحديث المرفقات والمواعيد واستكمال الطلب وإجراءات الوثيقة؛ يشترط بقاء صلاحية متابعة الطلب.
- إشعارات الإسناد للموظف المخول، ومرجع الطلب ووقت الحدث محفوظان حيث ينطبقان. لا تُضمّن مسارات المرفقات أو تفاصيل الاستجابات الخارجية أو الملاحظات الحساسة.
- `EmployeeNotificationController` و`CitizenNotificationController` يعزلان إشعارات كل حساب ويعيدان التحقق من صلاحية فتح السجل المرتبط. تدعم الواجهة القراءة الفردية والجماعية والتصفية.
- `notification-count.js` يحدّث النص الرقمي للعدّاد الموجود كل 30 ثانية، ويتوقف عند إخفاء الصفحة. لا يغير شكل أزرار الهيدر.
- لا مكتبات أو تغييرات مخطط قاعدة بيانات جديدة، ولا إرسال خارجي جديد. تنطبق الإشعارات على العمليات اللاحقة؛ لا تُنشأ إشعارات تاريخية وهمية.

## التحقق الفعلي

- مجموعة Laravel الكاملة على SQLite: **321 اختبارًا، 2276 تحققًا** نجحت.
- اختبارات MySQL المركزة على قاعدة `e_issuance_auth_testing` المعزولة: **64 اختبارًا، 425 تحققًا** نجحت.
- اختبارات التزامن على MySQL: **17 اختبارًا، 105 تحققات** نجحت.
- اختبارات JavaScript: **17 اختبارًا** نجحت.
- تجميع قوالب Blade وفحص Pint وفحص المسافات في Git نجحت.
- فحص HTTP المحلي: الرئيسية والدخول وملفا CSS والإشعارات الجديدان أعادت **200**.
- لم تتوفر جلسة متصفح للمعاينة البصرية؛ لا يغطي التحقق البرمجي المظهر الفعلي على الأجهزة المختلفة.

أوامر التحقق الأساسية:

```powershell
php vendor/bin/phpunit --do-not-cache-result
node --test tests/frontend/workspace-notifications.test.cjs tests/frontend/registration.test.cjs tests/frontend/portal-demo.test.cjs tests/frontend/local-password-recovery.test.cjs
php artisan view:cache
php artisan view:clear
```

اختبارات MySQL والتزامن تتطلب إعداد اتصال **قاعدة اختبار معزولة ينتهي اسمها بـ `_testing`**؛ لا تُشغّلها على قاعدة المشروع الفعلية.
