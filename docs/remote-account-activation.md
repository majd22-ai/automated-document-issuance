# تفعيل حساب المواطن إلكترونيًا

## الاستخدام
1. المواطن الذي لديه رقم وطني مسجل يفتح «تفعيل حسابي» من قائمته.
2. يدخل رقمه الوطني وجواله ويؤكد تحديث رقم الحساب عند الاعتماد إن كان مختلفًا. يطابق النظام الرقم المسجل ويفحص سجل المحاكاة إن كان مهيأ؛ هذا ليس اتصالًا بسجل حكومي حقيقي.
3. يتحقق برمز من ستة أرقام خلال ثلاث دقائق. خمس محاولات كحد أقصى، وفاصل إعادة إرسال دقيقة، وحدود إرسال للمواطن ولرقم الهاتف.
4. يرفع وجهي البطاقة وسيلفي يحمل فيه الوثيقة بجانب الوجه. عند عدم توفر البطاقة يختار شهادة الميلاد، ويقر بعدم توفر البطاقة، ويرفع الشهادة كاملة وسيلفي يحملها.
5. يراجع الموظف صاحب صلاحية `can_activate` لخدمة `identity-first-issue` الصور والبيانات ثم يوافق، أو يرفض، أو يطلب استكمالًا مع السبب. تصله إشعارات الطلب ويصل المواطن إشعار القرار.

لا حاجة لحضور المواطن لهذا المسار. أوقفت مسارات الموظف السابقة لإعداد الزيارة ومحاكاة الأصابع وإرسال/تأكيد رمز الزيارة (410). السجلات القديمة باقية، ومحاكاة بصمة **طلب إصدار البطاقة** منفصلة ولم تتغير.

## الحدود والحماية
- الحساب الأولي بلا رقم وطني يظل ملزمًا بمسار إصدار البطاقة والتحقق الرسمي القائم. شهادة الميلاد البديلة هنا لا تنشئ رقمًا وطنيًا ولا تتجاوز هذا الشرط.
- لا ينشأ حساب جديد ولا تتغير كلمة المرور عند التفعيل. الهاتف المقترح لا يعتمد إلا مع الموافقة؛ يسجل تغييره في التدقيق.
- OTP مخزن كتجزئة، يمسح بعد نجاح التحقق. جلسة رفع الوثائق ساعة من طلب الرمز، والمراجعة ممكنة لاحقًا. تغيير بيانات الحساب المرتبطة يبطل الإثبات ويستلزم تحققًا جديدًا.
- صور JPG/PNG حتى 5 MiB وأبعاد 300×300 على الأقل. أسماء عشوائية، وقرص `attachments` خاص. الوصول عبر مسار مصرح فقط و`no-store, private`؛ لا تستخدم `storage:link` لهذه الصور.
- بيانات الملفات وتاريخ نسخها مشفرة في سجل طلب التفعيل الموجود. إعادة التقديم تحفظ النسخة السابقة وسبب المراجعة. الموافقة مرتبطة بنسخة محددة ورمز عملية فريد ومعاملة وقفل؛ لا يجوز استعمال إثبات مستهلك مرة أخرى.
- السيلفي والتصوير ليسا فحص حيوية أو تعرفًا آليًا على الوجه. مراجعة مطابقة الوجه بشرية، وشهادة الميلاد تستلزم إقرار مراجعة إضافية.

## البيئة المحلية وSMS
يعمل العرض التجريبي فقط عند `APP_ENV=local` و`REGISTRATION_LOCAL_OTP=true`. تظهر نافذة «رمز تجريبي محلي لم يُرسل إلى شبكة الهاتف» للمواطن صاحب الجلسة، ويمكن نسخ الرمز وإغلاقها. لا تضف الرمز للسجلات.

خارج local لا تعمل المحاكاة. الربط الحالي يستخدم `UnavailableSms` عند غياب المحاكاة؛ يلزم تنفيذ وربط مزود حقيقي عبر `App\Contracts\RegistrationSms` مع إدارة الأسرار خارجيًا. دون ذلك تتوقف العملية ولا يقال إن SMS أرسل. نتيجة تجريبية قديمة لا تعتمد خارج local.

التصوير المباشر عبر المتصفح يحتاج HTTPS أو localhost وإذن الكاميرا. على الهاتف يمكن استخدام مدخل الصورة مع `capture=user`؛ متصفح الهاتف يقرر فتح الكاميرا، ولا يثبت ذلك الحيوية. فتح الموقع بعنوان LAN عبر HTTP قد يمنع getUserMedia، ويظهر شرح بديل واضح.

## التحقق
تختبر مجموعة RemoteActivation تدفق الموافقة، صلاحية الرمز والتجزئة ومحاولات التخمين، حماية الصور والصلاحيات، شهادة الميلاد والمراجعة الإضافية، الاستكمال وحفظ النسخ، الرفض، اختلاف نسخة الطلب، ورفض المحاكاة خارج local. اختبارات المسار السابق حدثت للتحقق من تقاعد نقاط HTTP وعدم تعديل التاريخ؛ اختبارات سياسات التفعيل والإصدار الرسمي بقيت ضمن CitizenActivationTest.

لم يختبر SMS حقيقي أو سجل حكومي أو جهاز بصمة أو دقة مطابقة الوجه، ولا يدعي التنفيذ توفرها. اختبار JavaScript يستخدم DOM مصغرًا ولا يغني عن تجربة كاميرا هاتف حقيقي.

## نتائج التنفيذ الفعلية
- البيئة المفحوصة: Laravel 12.65.0 وPHP 8.2.12، بيئة `local`.
- طبقت الترحيلة الجديدة بنجاح على قاعدة المشروع المحلية دون إعادة إنشاء الجداول أو حذف البيانات.
- اختبارات التفعيل المركزة: **52 ناجحًا، 414 تحققًا**.
- JavaScript: **اختباران ناجحان** (النوافذ والنسخ، تبديل نوع الوثيقة وإيقاف الكاميرا عند إخفاء الصفحة).
- `php artisan view:cache` نجح، و`npm.cmd run build` نجح. بقي تحذير بناء سابق لصورة header-left.webp التي تحل وقت التشغيل.
- التشغيل الشامل: **404 ناجحًا، اختبار متخطى، وفشلان**: `CivilRegistryGuidesTest::test_guides_live_in_identity_services_without_duplicating_them_on_home` بسبب رابط دليل الميلاد في الهيدر، و`GovernmentServicesTest::test_home_agency_requirement_menus_link_to_each_service_requirements` يتوقع 7 روابط بينما الصفحة تعرض 9. صفحات/روابط الخدمات المعنية غير معدلة في هذه المهمة. لم تُحذف هذه الاختبارات ولم يُتجاهل فشلها.
- نجح فحص تنسيق الملفات المعدلة و`git diff --check`. لا توجد تجربة ميدانية بكاميرا الهاتف أو SMS حقيقي.
