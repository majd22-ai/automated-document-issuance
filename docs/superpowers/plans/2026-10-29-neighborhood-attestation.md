# مصادقة عاقل الحارة المحلية

1. إعادة استخدام IdentityCardAttestation وIdentityAttestations والإشعارات وسجل AuditTrail. الاحتفاظ بالمصادقات القديمة ومسار إدارة الأمن والبصمة اللاحق.
2. إضافة محافظات ومديريات ودليل عُقّال مستقل عن حسابات المستخدمين؛ استيراد قائمة جغرافية محلية ثابتة موثقة. إدارة الدليل للأدمن فقط مع تحقق الارتباط.
3. منع جهة العمل والشهود كاختيار مصادقة جديد، وإزالة حقل جهة عمل مقدم الطلب؛ الاحتفاظ بالبيانات التاريخية والشهود في الاستمارة.
4. قوائم محافظة ← مديرية ← عاقل وحيه؛ الخادم يتحقق من نطاق العاقل والحي. تغيير اختيار المحافظة/المديرية يمسح التابعين. لا تُعرض أرقام العُقّال الشخصية للمواطن.
5. محاكاة جوال داخل dialog للموظف المخول، مع خطوة تحقق برمز بيئة محلي أو بصمة محاكاة على الخادم. المواطن يطلب فقط ولا يعتمد طلبه. منع التكرار بقفل السجل والمعاملة الحالية، وتسجيل المحاولات دون الرمز أو بيانات حيوية.
6. اختبارات الجغرافيا والصلاحيات والنطاق والرمز والمحاكاة والتكرار والرفض والإجراءات السابقة، ثم migration إضافية غير مدمرة وتجميع Blade وتوثيق التشغيل.
