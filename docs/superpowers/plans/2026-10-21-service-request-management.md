Extend existing table with request_type, request_data, notes, declaration/submission timestamps, nullable submission_token unique and active_request_key unique, and explicitly citizen-visible reason. No drafts/cancellation UI without approved policy.

Add configurable application_fields to government_services with allowlisted schema. Preview validates on server, keeps reviewed payload in the authenticated session for 30 minutes and binds token to owner/service/current service and account fingerprints. Final POST accepts only token+declaration; recheck owner, service, fingerprints, inputs and eligibility inside a transaction locking citizen then service. Generate REQ-ULID reference under existing unique index; retain idempotent token and active owner/service/operation hash under unique indexes. Conservative legacy duplicate handling; canonical rejected/cancelled/completed statuses are terminal, canonical live statuses cannot be configured away.

Reuse CitizenDataController for filtered, paginated citizen/employee read-only lists/details. New ServiceRequestController only owns preview/confirmation/success, Submission service owns transactional creation. Policy scopes all record access. Define states and allowed transitions for later review integration, deny transition permissions to all existing roles until requirement8, and prevent arbitrary model/HTTP state changes. Completion remains blocked until issuance integration.
