# استعادة كلمة المرور المحلية على خطوات

هذا المسار يحل محل الطريقة القديمة التي كانت تعيد تعيين الكلمة فور إدخال البريد.

1. افتح `/forgot-password` وأدخل البريد المسجل لحساب نشط.
2. تظهر نافذة تعرض البريد و**رمز استعادة** من ستة أرقام، مع زر نسخ وعلامة × للإغلاق. الرمز ليس كلمة مرور جديدة، ولم يُرسل بريد فعلي.
3. انسخ الرمز وأغلق النافذة وأدخله في حقل الرمز، ثم اضغط «التحقق والمتابعة».
4. أدخل كلمة مرور جديدة وتأكيدها؛ ثماني خانات على الأقل تتضمن حروفًا وأرقامًا ورمزًا.
5. بعد الحفظ تنتقل إلى صفحة تسجيل الدخول وتظهر رسالة نجاح. الكلمة القديمة لا تعمل والجديدة تعمل. لم تتغير كلمة المرور قبل الخطوة الرابعة.

## الضوابط

- التفعيل يتطلب `APP_ENV=local` و`LOCAL_PASSWORD_RECOVERY=true` مع `php artisan config:clear`. خارج `local` لا تعمل ميزة العرض ومسارا التحقق والحفظ، حتى إذا كان العلم مفعلاً. لتعطيل التجربة اجعل العلم false. لا يلزم حذف كود الحماية عند النشر.
- المسار يعيد استخدام Laravel Password Broker وجدول الرموز الحالي. لا توجد Migration أو جداول مستخدمين جديدة.
- الرمز صالح عشر دقائق ولخمس محاولات. طلب رمز جديد يبطل السابق، مع انتظار دقيقة وحدود الطلبات. فشل الرمز أو عدم تطابق الكلمتين لا يغيّر كلمة المرور.
- النافذة تعرض الرمز مرة واحدة، ويُحفظ عرضها مشفرًا مؤقتًا في جلسة صاحب الطلب. تحديث الصفحة لا يعيد إظهاره؛ اطلب رمزًا جديدًا إذا فقدته. فشل نسخ الحافظة يحدد الرمز للنسخ اليدوي بـ Ctrl+C.
- الجلسة تحفظ تجزئة الرمز ورمز Broker مشفرًا وهوية الحساب من الخادم. لا يعتمد مسار الحفظ بريدًا أو معرّف مستخدم مرسلًا من العميل. يُعاد فحص نشاط الحساب ونسخة المصادقة قبل الحفظ، مع قفل صف الحساب والجلسة. تغير الحساب أثناء الاستعادة يمنع إكمالها.
- الحفظ يدوّر remember_token ويبطل رموز الاستعادة والجلسات القديمة، ثم يمسح حالة الاستعادة. لا يسمح بإعادة استخدام رمز مكتمل. لا تتغير أدوار الحساب أو صلاحيته أو اعتماد الهوية.
- لا تسجل رموز أو كلمات مرور في السجلات. الصفحات no-store وno-referrer. تبقى CSRF وحدود المحاولات فعالة.
- لم تتغير آلية الاستعادة خارج الوضع المحلي؛ الواجهة الأكاديمية لا ترسل بريدًا فعليًا. الربط البريدي الحقيقي يتطلب تكاملًا مستقلًا.

## الملفات والتحقق

خدمة `LocalPasswordRecovery`، متحكم `LocalPasswordRecoveryController`، المسارات القائمة، واجهة `auth/forgot-password` ورسالة النجاح في `auth/login`، ملفا `public/css/local-password-recovery.css` و`public/js/local-password-recovery.js`، واختبارات المصادقة وJavaScript.

```powershell
php vendor/bin/phpunit --do-not-cache-result --filter="UserAuthenticationTest|RegistrationFlowTest"
node --test tests/frontend/local-password-recovery.test.cjs
php artisan view:cache
php artisan view:clear
```

لا تتغير كلمة مرور أي حساب فعلي خلال الاختبارات؛ قواعد الاختبار معزولة.

نتائج التحقق الفعلية: 61 اختبارًا / 480 assertion على SQLite، و31 اختبارًا / 261 assertion للمصادقة على MySQL المعزولة، و3 اختبارات JavaScript للنسخ والإغلاق. نجح Blade وPint وفحص PHP. الصفحة وملفا CSS/JS تعيد HTTP 200 محليًا. حدود المعدل منفصلة لطلب الرمز والتحقق والحفظ حتى لا تستهلك خطوات الاستعادة حصة تسجيل الدخول.
